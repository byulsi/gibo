# Guru Maker Trademark Guidelines

This document covers project marks, not source-code licensing. Source code and
documentation are licensed through `LICENSE` and `NOTICE`.

## Project marks

Project marks include the names "Guru Maker" and "Agents & Cents", official
logos and visual identity assets, and names of official hosted or commercial
offerings. The Apache License does not grant trademark rights.

You may truthfully refer to the project, describe compatibility, preserve
notices, and discuss, review, benchmark, or teach it. Those uses must not imply
sponsorship, endorsement, verified investment performance, or official status.

Written permission is required to use project marks in a product, company,
domain, paid marketplace listing, certification, or managed service in a way
that suggests an official offering. Forks making material changes should use a
distinct name.

Use of the marks must never imply endorsement of an investment strategy,
research conclusion, Guru Pack, order, broker, data provider, or financial
outcome.
